# MotoRacer - Retro Pseudo-3D Motosiklet Yarış Oyunu

Bu proje, HTML5 Canvas, modern CSS ve saf JavaScript kullanılarak geliştirilen retro tarzda bir pseudo-3D motosiklet yarış oyunudur.

## Proje Yapısı

- `index.html` - Oyunun ana giriş noktası ve UI katmanı.
- `style.css` - Modern, premium cam tasarımı (glassmorphism) ve arayüz stilleri.
- `src/game.js` - Ana oyun döngüsü ve Canvas çizim motoru.
- `src/track.js` - Yol kıvrımları, tepeler ve parallax arka plan yönetimi.
- `src/player.js` - Motosiklet kontrolü, fizik ve animasyonlar.
- `src/assets/` - Oyun içi görseller (motosiklet, engeller, arka plan).

## Nasıl Çalıştırılır?

Bu dizini aktif çalışma alanınız (active workspace) olarak ayarladıktan sonra, yerel bir geliştirme sunucusu (örneğin VS Code Live Server veya basit bir HTTP sunucusu) ile `index.html` dosyasını tarayıcınızda açabilirsiniz.
